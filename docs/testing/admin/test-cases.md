# Админка и CRM: тест-кейсы

Предусловия: изолированный стенд `/admin/`, роли и данные из [подготовки](../test-data.md). Для проверок прав повторять действие прямым API-запросом: скрытая кнопка сама по себе не является защитой. Все кейсы изначально NOT RUN.

## Матрица доступа

| Действие | Без сессии | viewer | manager | owner |
|---|---|---|---|---|
| Просмотр заявок/контактов, CRM, контента, каталога, медиа, метрик, аудита | Нет | Да | Да | Да |
| Изменение заявки/контактов, работа с CRM, контентом и загрузка медиа | Нет | Нет | Да | Да |
| Изменение каталога, цен и политики скидок | Нет | Нет | Нет | Да |
| Сотрудники и контролируемый просмотр БД | Нет | Нет | Нет | Да |
| Смена собственного пароля | Нет | Да | Да | Да |

Публичные `/api/v1/content`, `/api/v1/catalog` и опубликованные изображения доступны без staff-сессии; это не доступ к административным маршрутам. Фильтр CRM «Мои» не ограничивает право сотрудника читать другие заявки.
