# Фронтенд: тест-кейсы

Предусловия: изолированный работающий сервер, данные D/C/Q/O из [подготовки](../test-data.md). Базовые страницы: `/`, `/status.html`, `/privacy.html`. Каждый раздел «варианты» выполнять по отдельности. Все кейсы изначально NOT RUN.

| ID | Приоритет | Сценарий и действия | Ожидаемый результат |
|---|---|---|---|
| FE-01 | P0 | Открыть `/`, дождаться каталога и контента; открыть форму выбора поездки. | Основные блоки и изображения доступны, нет необработанных ошибок JS; цены соответствуют C, форма работает через сервер. |
| FE-02 | P1 | Перейти по якорям, кнопкам «Выбрать даты», ссылкам статуса/политики; на узком экране открыть меню и выбрать раздел. | Переходы ведут к нужным разделам; меню закрывается после выбора, `aria-expanded` соответствует состоянию; фиксированная панель не перекрывает форму. |
| FE-03 | P1 | Открыть форму, изменить даты, закрыть через крестик/Escape/вне окна; повторно открыть; перейти к контактам и обратно. | Окна закрываются предсказуемо, шаги и сумма согласованы с текущей поездкой; фокус доступен с клавиатуры и не остаётся в скрытом окне. |
| FE-04 | P0 | Задать Q; сравнить быстрый расчёт, строки модального окна, серверный quote и независимую формулу. | Число ночей, места, услуги, скидка и итог совпадают; копейки форматируются в рубли без потерь. |
| FE-05 | P1 | Выбрать заезд сегодня/вчера, одинаковые даты/обратный период, 1/365/366 ночей; очистить дату; изменить заезд позже текущего выезда. | Валидные периоды принимаются; недопустимые не отправляются как заказ, ошибка понятна; при автокоррекции выезда итог пересчитан. Сервер также проверяет период. |
| FE-06 | P1 | Установить число ночей на пороге скидки и на одну ночь меньше; нажать кнопку предложения «Рассчитать … ночей». | Скидка начинается по текущей политике C, применяется только к проживанию; кнопка задаёт срок политики, не устаревшую константу. |
| FE-07 | P1 | Переключать категории услуг; добавить услугу с карточки; нажимать +/− до 0 и 100, попробовать выйти за границы. | Фильтр и `aria-pressed` согласованы; количества 0–100, каждая услуга считается за поездку, выбранное не исчезает из расчёта при фильтрации. |
| FE-08 | P0 | Отключить проживание, оставить одну услугу; затем обнулить все услуги; снова включить проживание. | В первом случае считаются только услуги без скидки на них; пустую заявку отправить нельзя; при включении места и ночи возвращаются в расчёт. |
| FE-09 | P1 | В контактах проверить пустое/пробельное имя, длину 80/81, телефон с 9/10/15/16 цифрами и буквами, комментарий 1000/1001, снятое согласие. | Валидные значения принимаются; неверные блокируются или получают понятную ошибку API; ограничения длины работают. Ссылка на обработку данных открывается. |
| FE-10 | P0 | Отправить O через оба шага формы с синтетическими контактами и согласием. | Появляются номер и код; заявка сохранена один раз и имеет pending; явно указано, что места не зарезервированы, оплаты не было. |
| FE-11 | P0 | Двойной клик отправки; отдельно задержать/потерять ответ после сохранения и повторить отправку без изменения формы и перезагрузки. | Кнопка блокируется на запросе; повтор использует тот же ключ и тело, возвращает тот же заказ, дубля в БД нет. |
| FE-12 | P0 | После quote изменить тариф на тестовом стенде владельцем; отправить старую форму. | `PRICE_CHANGED`: показан новый расчёт, требуется повторная отправка после просмотра, автоматически заявка не создаётся. |
| FE-13 | P1 | Скачать расчёт до отправки; после создания скачать подтверждение, проверить содержимое локально. | План не создаёт заказ и помечен как расчёт; подтверждение содержит номер и пригодный для статуса код, даты/сумма совпадают; русские символы читаются. Не прикладывать код к отчёту. |
| FE-14 | P0 | Вставить код O на `/status.html`; повторить с пробелами вокруг, пустым, неправильным и неизвестным 64-hex кодом. | Правильный код показывает только минимальный статус/номер/сумму; плохой даёт понятную ошибку. Код передаётся в Authorization, не в URL; контактов и внутренних заметок нет. |
| FE-15 | P1 | Заблокировать загрузку каталога; отдельно симулировать offline/500/таймаут quote, orders и status; восстановить сеть. | Нет ложного успеха; при недоступных тарифах отправка заблокирована; после ошибок доступен повтор, введённое не теряется без причины. Обработка 429 не выглядит как сохранённая заявка. |
| FE-16 | P1 | После успешной заявки проверить URL, browser storage и запросы; обновить страницу. | Код не хранится в localStorage и не включён в URL; после перезагрузки код и ключ из памяти не восстанавливаются автоматически. Пользователь получил указание скачать код. |
| FE-17 | P1 | Через тестовую админку сохранить текст с `<b>тест</b>` и безопасной XSS-пробой, выключить блок/услугу; обновить сайт. | Текст не исполняется как HTML/JS, видимость соответствует настройкам; отключённую услугу нельзя заказать. Контент и карточки не ломают страницу. |
| FE-18 | P1 | Пройти FE-10 и FE-14 на 390 px и клавиатурой; проверить Tab/Shift+Tab/Enter/Escape, метки полей и сообщения. | Все действия доступны, виден фокус; ошибки связаны с полями/объявляются; диалог прокручивается, итог и кнопки не перекрыты. |
| FE-19 | P2 | Повторить основной путь на 320/768/1024/1440 px, масштабе 200% и в доступных Firefox/WebKit. | Нет горизонтального переполнения основного интерфейса, обрезанных сумм/текста или недоступных действий; различия фиксируются с браузером. |
| FE-20 | P2 | Проверить изображения, alt, источники, длинные названия услуг; перезагрузить с медленной сетью. | Нет сломанных изображений и скачков, делающих форму недоступной; подписи/ссылки читаемы; загрузка не оставляет зависший интерфейс. |
