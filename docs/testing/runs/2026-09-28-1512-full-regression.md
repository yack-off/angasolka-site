### DEF-0010: код статуса с пробелами

- Кейс: FE-14; P2/S3, ранее зарегистрирован.
- Предусловия: одна синтетическая заявка на временной PGlite.
- Шаги: открыть `/status.html`; ввести её действующий 64-hex код с одним пробелом слева и справа; нажать «Проверить статус».
- Ожидается: пробелы удаляются, виден тот же статус.
- Фактически: HTML-валидация показывает «Введите данные в указанном формате» и не отправляет запрос. Без пробелов код работает.
- Исправление и повтор после него: не выполнялись.
