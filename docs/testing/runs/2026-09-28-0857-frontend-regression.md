# Отчёт о тестировании — продолжение проверки фронтенда 27–28.09.2026

## Контекст

- Запрос: продолжить тестирование публичного фронтенда и записать найденные дефекты в постоянный бэклог. Исправления приложения не запрашивались.
- Период: вечер 27.09.2026 — утро 28.09.2026, окончание около 09:00 Asia/Jerusalem; были перерывы и перезапуски изолированной среды. Точное время начала расширенного прогона не зафиксировано. Не считать этот интервал непрерывным временем тестирования.
- Версия: рабочее дерево проекта целиком неотслеживаемое, commit для сравнения отсутствует. public/ и src/ в рамках этого прогона не менялись. [SHA-256 проверенных основных файлов](2026-09-28-frontend-source-hashes.json).
- Среда: Windows, Node 24.19.0, локальный сервер http://127.0.0.1:4183; PGlite memory, не рабочая БД.
- Браузер: Codex In-app Browser (Chromium; точная версия не предоставлена); 1280×720 и адаптивные размеры 390×844, 320/768/1024/1440×900. Это эмуляция ширины окна, не тест физического смартфона.
- Подготовка: scripts/frontend-browser-qa.ts запускает реальный buildApp и миграции, создаёт тестового владельца. Каталог/контент/статус изменяются через существующие admin API. Контакты синтетические, секреты только в памяти процесса.
- Telegram worker, платежи, публикация и внешняя отправка не запускались. Данные рабочих demo/production не затронуты.
- Добавлены только тестовые утилиты, отчёт, обезличенные свидетельства и записи бэклога.

## Метод и доказательства

Отказы воспроизводились локальным HTTP-адаптером поверх реального приложения: 500/429, обрыв до/после сохранения и задержка 17 секунд при клиентском таймауте 15 секунд. Это не эмуляция аппаратного offline. События фиксируют только маршрут, HTTP-статус, сумму и булевы признаки равенства ключа/тела/заказа; контактов и кодов в них нет.

Сегменты — независимые базы в памяти после перезапуска:
- [segment1](2026-09-28-frontend-segment1.json): двойной клик, потеря ответа, смена тарифа; три заявки.
- [segment2](2026-09-28-frontend-segment2.json): границы, 500/429, таймаут после сохранения, публичный статус и contacted; одна заявка.
- [segment3](2026-09-28-frontend-segment3.json): копейки, ошибки quote/status, мобильная отправка, CMS; одна заявка.
- [segment4](2026-09-28-frontend-segment4.json): длинное название и обычная арифметика; заявок не создавалось.

JSON содержит последние 40 событий каждого сегмента, а не полную сетевую трассу. Итоги UI записаны ниже по наблюдениям в браузере; не для каждого клика есть отдельный сохранённый скриншот. Скачанные подтверждения проверялись локально и намеренно не приложены.

При работе встречались перезапуски/недоступность тестового процесса и техническая ошибка «QA harness failure». Их не считали дефектами приложения. Неудачная подготовка food.enabled получила 400; повтор с фактическим полем active выполнен успешно.

- Всего 95 строк вариантов: PASS 73, FAIL 9, BLOCKED 3, NOT RUN 10, N/A 0.
