# Отчёт о тестировании — админка и CRM, 28.09.2026

## Контекст

- Запрос/объём: P0 smoke админки/CRM по `docs/testing/admin/test-cases.md`; дополнительно базовый просмотр метрик. Это не полный регресс.
- Время: 28.09.2026, окончание 14:40 Asia/Irkutsk; точное время начала не фиксировалось.
- Версия: у репозитория нет коммита `HEAD`; исходные файлы были untracked до прогона. Изменён только этот отчёт.
- Среда: Windows, Node 24.19.0, pnpm 11.25.0; отдельный сервер `http://127.0.0.1:4181` из `scripts/admin-browser-server.ts`.
- БД: PGlite `memory://`, миграции применены скриптом стенда. Рабочие `data/postgres` и `data/demo/postgres` не использовались.
- Браузер: Codex in-app Chromium, версия не предоставлена; фактическая ширина при попытке установить 390 px оставалась 711 px. Обычная ширина отдельно не зафиксирована.
- Подготовка: локальный владелец и одна синтетическая заявка созданы в браузере; пароль и телефон в отчёт не внесены. Telegram выключен.
