# Проверка текущей версии

2026-09-14, Windows, Node.js 24.19.0.

- TypeScript strict (`tsc --noEmit`) — без ошибок.
- Синтаксис `public/app.js` — без ошибок.
- 10 интеграционных тестов API — успешно: расчёт, скидка, услуги без проживания, входная валидация, идемпотентность параллельных запросов, откат при подмене цены, секретный статус, защита файлов и Origin, OpenAPI, rate limiting, календарь и сохранность БД после открытия заново.
- В браузере пройден путь: даты → серверный расчёт → синтетические контакты и согласие → сохранённая заявка → статус по секретному коду.
- Админка проверена в отдельном браузерном сервере на временной БД: первичная настройка владельца, вход, изменение текста блока с публикацией на сайте, выбор изображения, добавление услуги, серверный расчёт новой услуги, создание заявки и её появление в списке заявок.
- 17 интеграционных тестов backend и админки прошли до финальной механической чистки HTML-маркеров; после неё повторный запуск тестов был заблокирован лимитом среды на дочерние процессы. `pnpm check`, синтаксис браузерных скриптов и `diff --check` проходят.
- В локальной рабочей БД оставлена одна явно помеченная тестовая заявка «Тестовая заявка — проверка сайта», без реальных контактных данных. Уведомления не отправлялись.
- PGlite и SQL-миграции проверены. Ветка внешнего PostgreSQL реализована, но не прогонялась против отдельного PostgreSQL в этой среде; для этого предусмотрен `TEST_DATABASE_URL`.
- Нагрузочное тестирование, реальное резервирование мест, платежи и доставка outbox-событий не входят в текущую реализацию. Авторизация сотрудников реализована для кабинета с локальной первичной настройкой и production-командой `pnpm admin:create`.

Песочница Windows блокировала дочерние процессы tsx/тестов, поэтому запуск интеграционных проверок и сервера был выполнен с предоставленным пользователем разрешением. После первичной установки выполнен повторный `pnpm install`: зависимости актуальны, сборка esbuild завершена.
