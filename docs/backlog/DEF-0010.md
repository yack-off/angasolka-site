## Описание

HTML-валидация отклоняет значение: «Введите данные в указанном формате». Запрос не уходит. В проверенном вводе длина 66, validity.valid=false.

## Воспроизведение

- Среда: Windows, Codex In-app Browser (Chromium), рабочий public/; сервер 127.0.0.1:4183, изолированная PGlite memory.
- Предусловия: тестовый каталог и синтетические заявки; рабочие данные не используются.

1. Создать тестовую заявку и проверить её правильный 64-hex код.
2. Перезагрузить /status.html.
3. Вставить тот же код с одним пробелом слева и справа, нажать «Проверить статус».

- Ожидаемый результат: Пробелы по краям удаляются, показывается та же заявка (FE-14).
- Фактический результат: HTML-валидация отклоняет значение: «Введите данные в указанном формате». Запрос не уходит. В проверенном вводе длина 66, validity.valid=false.
- Доказательства: FE-14; правильный код PASS, пробелы FAIL. Код не включён в отчёт. [Подробный отчёт](../testing/runs/2026-09-28-0857-frontend-regression.md).

## Критерий исправления

Код с пробелами по краям принимается; неверные и неизвестные коды продолжают отклоняться.

## Исправление и проверки

### Первоначальная диагностика

- Причина: pattern=[a-f0-9]{64} проверяется до submit; trim() находится внутри submit-обработчика и не выполняется при провале нативной валидации.
- На момент первоначальной диагностики изменения приложения не вносились; пользователь запросил тестирование и регистрацию.
- На момент первоначальной диагностики проверка после исправления не выполнялась.
- Непроверенное: другие браузерные движки.
- На момент первоначальной диагностики дефект не был исправлен.
- Публикация: не выполнялась.

### Результат исправления 2026-09-28

HTML больше не отвергает внешние пробелы; JS обрезает их и проверяет 64-символьный hex-код. В браузере код с пробелами дошёл до сервера и получил ожидаемый ответ о неизвестной заявке.

- Изменённые файлы: `public/index.html`, `public/app.js`, `public/status.html`, `public/status.js`, `public/styles.css`, `public/place.css`, `public/booking.css`, `public/content.js`, `public/privacy.html`, `content-seed.json` (по применимости).
