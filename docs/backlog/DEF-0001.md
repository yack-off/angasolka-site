## Описание

На первом шаге окна «Проверьте поездку» после нажатия на плюс у блока «Добавить обед, баню или активность» раскрывается список услуг. Под последней услугой появляются два горизонтальных разделителя подряд перед блоком «Приезжаете без ночёвки?».

## Воспроизведение

- Среда: мобильный браузер на iPhone по виду скриншотов; точные модель, браузер, версии ОС и приложения неизвестны.
- Предусловие: открыто окно «Проверьте поездку», шаг 1 из 2 — «Состав поездки».
- Шаги по сообщению пользователя: раскрыть дополнительные услуги нажатием на плюс; прокрутить к концу списка.
- Ожидаемый результат: один разделитель между концом списка услуг и следующим блоком, без дублирующей полосы.
- Фактический результат: под услугой «Туристический маршрут» две линии с небольшим вертикальным промежутком.
- На втором скриншоте блок «Приезжаете без ночёвки?» также раскрыт; влияние этого состояния на дефект ещё не проверено.
