# DEF-0006 — Лишняя обводка кнопки закрытия при открытии окна

- Дата регистрации и обновления: 2026-09-27.
- Источник: сообщение пользователя и [общий скриншот с DEF-0005](attachments/DEF-0005/close-button.jpg).
- Основная область: Фронтенд.
- Связанные области: нет.
- Тип: замечание к визуальному поведению фокуса.
- Приоритет: P3 — ненужное визуальное выделение, работа окна не заблокирована.
- Критичность: S4 — косметическое поведение.
- Статус: Исправлен
- Подтверждение: обводка видна на скриншоте; её появление и исчезновение описаны пользователем, самостоятельно не воспроизведены.
- Связанные ID: DEF-0005 — выравнивание крестика той же кнопки.

## Описание и воспроизведение

При открытии окна «Проверьте поездку» вокруг кнопки закрытия появляется оранжевая обводка. По сообщению пользователя после клика внутри окна она исчезает. Пользователь предлагает убрать это выделение.

- Среда: мобильный экран iPhone по скриншоту; точные браузер, ОС и версия приложения неизвестны.
- Шаги по сообщению: открыть окно, осмотреть кнопку закрытия, нажать внутри окна и сравнить её вид.
- Фактически: при открытии есть обводка, после взаимодействия внутри окна она пропадает.
- Ожидается: при открытии касанием или мышью кнопка не получает лишнюю видимую обводку.
- Гипотеза для проверки: обводка может быть индикатором автоматически установленного фокуса. Причина по коду не установлена.

## Предлагаемое исправление и критерии

Убрать ненужное начальное выделение для касания и мыши, сохранив видимый индикатор при управлении клавиатурой. Не удалять стили фокуса глобально и не нарушать перевод фокуса внутрь модального окна.

Проверить открытие и повторное открытие касанием/мышью, переходы Tab и Shift+Tab, видимость фокуса при клавиатурной навигации, закрытие кнопкой и Escape, возврат фокуса к элементу открытия. После исправления DEF-0005 обводка, когда она нужна клавиатурному пользователю, и крестик должны быть выровнены относительно кнопки.
