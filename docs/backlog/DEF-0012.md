# DEF-0012 — Отчёт и реестр недоступны пользователю со смартфона

- Дата регистрации: 2026-09-28
- Дата обновления: 2026-09-28
- Источник: сообщение пользователя «Отчет о тестах и реестр бэклога не открывается»; уточнение об удалённом клиенте смартфона.
- Основная область: Документация
- Связанные области: доставка результатов проверки
- Приоритет: P2 — пользователю нужен доступ к результатам текущей работы.
- Критичность: S3 — затронуто чтение отчёта; краткое содержание можно дать в чате.
- Статус: Новый
- Подтверждение: сообщение пользователя; на его смартфоне не воспроизводилось.
- Зависимости и связанные ID: нет.

## Описание

Пользователь не может открыть выданные ссылки на отчёт и постоянный реестр, находясь вне компьютера и пользуясь клиентом смартфона. Это проблема доставки документов, а не подтверждённый дефект публичного сайта.

## Воспроизведение

1. Открыть предыдущий ответ с локальными ссылками в удалённом клиенте смартфона.
2. Нажать ссылку отчёта или «Реестр бэклога».

- Ожидается: результат проверки можно прочитать сейчас со смартфона.
- Фактически: по сообщению пользователя ссылки не открываются.
- Модель устройства, версия клиента, точная ошибка: неизвестны.
- Предполагаемая причина: локальный путь рабочего компьютера недоступен удалённому клиенту; технически не подтверждена на устройстве пользователя.

## Критерий исправления

Пользователь получает доступный на смартфоне отчёт/реестр и подтверждает возможность его открыть. До этого карточку не закрывать.

## Исправление и проверки

- Обходной путь: итог и новые записи продублированы текстом в чате; файлы сохранены в проекте для последующей работы.
- Публичная публикация документов: не выполнялась.
- Проверка на смартфоне пользователя: не выполнена.
- Дата исправления: не исправлен.
