# DEF-0007 — Скачанный план содержит старую сумму после обновления тарифа

- Дата регистрации: 2026-09-28
- Дата обновления: 2026-09-28
- Источник: [прогон фронтенда](../testing/runs/2026-09-28-0857-frontend-regression.md)
- Основная область: Фронтенд
- Связанные области: —
- Приоритет: P1 — Пользователь получает противоречащий экрану расчёт стоимости.
- Критичность: S3 — Ошибочен скачиваемый предварительный план; сервер сохраняет правильную сумму, платежа нет.
- Статус: Исправлен
- Подтверждение: воспроизведено в браузере
- Зависимости и связанные ID: DEF-0009 — другая причина расхождения сумм

## Описание

На экране 3 002 ₽, в файле «ИТОГО: 3 000 ₽» и старый тариф 1 500 ₽.

## Воспроизведение

- Среда: Windows, Codex In-app Browser (Chromium), рабочий public/; сервер 127.0.0.1:4183, изолированная PGlite memory.
- Предусловия: тестовый каталог и синтетические заявки; рабочие данные не используются.

1. Открыть поездку: одно место, две ночи, тариф 150 000 коп., quote 300 000 коп.
2. Владельцем тестового стенда изменить тариф на 150 100 коп.
3. Отправить старую форму: получить PRICE_CHANGED и новый итог 3 002 ₽.
4. До повторной отправки нажать «Скачать расчёт».

- Ожидаемый результат: Файл соответствует пересчитанному экрану: 3 002 ₽.
- Фактический результат: На экране 3 002 ₽, в файле «ИТОГО: 3 000 ₽» и старый тариф 1 500 ₽.
- Доказательства: FE-12, FE-13; segment1 подтверждает 409 → quote 300200. Файл проверен локально, секретов в плане нет. [Подробный отчёт](../testing/runs/2026-09-28-0857-frontend-regression.md).

## Критерий исправления

После PRICE_CHANGED строки и итог скачанного плана совпадают с актуальным показанным расчётом.

## Исправление и проверки

### Первоначальная диагностика

- Причина: Обработчик #save-trip вызывает calculation() с каталогом, загруженным при старте. Обновлённый serverQuote не используется.
- На момент первоначальной диагностики изменения приложения не вносились; пользователь запросил тестирование и регистрацию.
- На момент первоначальной диагностики проверка после исправления не выполнялась.
- Непроверенное: другие браузерные движки.
- На момент первоначальной диагностики дефект не был исправлен.
- Публикация: не выполнялась.

### Результат исправления 2026-09-28

Скачанный план использует актуальный server quote для неизменённой поездки. После PRICE_CHANGED экран и скачанный файл показали 6 759 ₽ при 1 502 ₽ за ночь.

- Изменённые файлы: `public/index.html`, `public/app.js`, `public/status.html`, `public/status.js`, `public/styles.css`, `public/place.css`, `public/booking.css`, `public/content.js`, `public/privacy.html`, `content-seed.json` (по применимости).
- Проверки: [отчёт прогона](../testing/runs/2026-09-28-frontend-fixes.md).
- Публикация: не выполнялась.
