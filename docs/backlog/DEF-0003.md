## Описание

Сейчас карточки «Ангасолка с высоты» и «Мосты через Ангасолку» идут в порядке: фото → название и описание → источник. Пользователь предлагает сначала описание, затем фото и источник; также спрашивает, можно ли обойтись без источника и зачем он нужен.

## Воспроизведение и ожидаемый результат

- Среда: мобильный экран iPhone по скриншоту; точные браузер, ОС и версия сайта неизвестны.
- Шаги будущей проверки: открыть главную страницу, прокрутить галерею раздела «Та самая Ангасолка».
- Фактически: текст, поясняющий фотографию, расположен после неё; происхождение фото вынесено отдельной строкой в каждой карточке.
- Предпочтительно: название и описание → соответствующая фотография → компактная атрибуция только там, где она нужна. Технические сведения о происхождении сохранять в документации даже при удалении из карточки.

## Исследование источников

- В `public/index.html` обе карточки используют `figcaption` после изображения. В `content-seed.json` есть подписи для CMS; `public/app.js` также формирует общий блок `photo-credit`. При исправлении учесть все представления и не нарушить CMS-привязки.
- Для мостов код ссылается на [Mosty na st.Angasolka.jpg](https://commons.wikimedia.org/wiki/File:Mosty_na_st.Angasolka.jpg), автор Kolchak1923. По поисковому результату страницы Wikimedia Commons от 27.09.2026 для файла указана CC0; прямое открытие страницы инструментом не удалось. Перед реализацией удаления подписи повторно сверить карточку оригинала и соответствие локального файла.
- [CC0](https://creativecommons.org/publicdomain/zero/1.0/) не устанавливает условия атрибуции, поэтому подпись для такого материала не нужна именно как требование CC0; она может служить указанием происхождения и признанием авторства.
- Нельзя переносить этот вывод на все фотографии Wikimedia: условия разных файлов отличаются. [Руководство Creative Commons по повторному использованию](https://creativecommons.org/reusing-cc-licensed-content/) описывает атрибуцию для лицензий CC.
- Для панорамы в проекте указан сайт angasolka.net; условия использования или разрешение правообладателя в рамках этой регистрации не установлены. Само указание источника не заменяет разрешение. Решение об удалении этой подписи пока не принято.

## Предлагаемое исправление и критерии

1. Перестроить карточки в порядок «название и описание → фото»; нужные подписи оставлять компактными под фото.
2. Необязательные подписи убрать из карточек после проверки условий; источники и условия сохранить в документации проекта. Пользователь ещё не выбрал окончательный вариант отображения источников.
3. Проверить мобильную и широкую компоновку: описание однозначно относится к своему фото, между карточками понятные отступы, открытие полного изображения работает, CMS-поля сохранены.
